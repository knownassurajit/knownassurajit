# Security Policy

## Security & Secrets Management

This repository contains GitHub Profile Readme automation scripts.
- No personal access tokens (PATs), API keys, or credentials are hardcoded into script files.
- Secret tokens are managed via GitHub Repository Secrets (`GH_PAT` / `GITHUB_TOKEN`).

## Reporting a Vulnerability

If you discover a security issue or credential exposure in any script:
- Report it immediately and privately to the repository owner.
