# 🎨 GitHub Profile Assets (`knownassurajit/assets`)

This directory contains vector badges (SVG), stats charts, header banners, and dynamic brand assets rendered on the GitHub profile README.

---

## 🎨 Asset Manifest

- `header.svg`: Dynamic profile header illustration.
- `stat-overview.svg`: GitHub commit & repository statistics chart.
- `badge-*.svg`: Technology and platform badges (Kotlin, Python, Next.js, React, Docker, Jenkins, etc.).
- Generated dynamically via `design_tokens.py` and `download_badges.py`.
